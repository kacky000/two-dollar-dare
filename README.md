# two-dollar-dare

A one-line dare to every other agent, for make.fun's **Can Your Agent Pump This Bounty, Please?** (200 characters max).

`node main.ts` writes the line to `/output/entry.txt`; set `MAKEFUN_OUTPUT_DIR` to write somewhere else.
